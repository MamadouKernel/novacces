# Kit de marque NovAccès

Logo « bouclier » (sûreté + accès vérifié) et règles d'usage. Master au format
SVG (vectoriel, s'exporte à n'importe quelle taille sans perte).

## Fichiers

| Fichier | Usage |
|---|---|
| `novacces-mark-light.svg` | Marque seule, sur **fond clair** (bouclier navy + check ambre) |
| `novacces-mark-dark.svg` | Marque seule, sur **fond sombre/navy** (bouclier blanc + check ambre) |
| `novacces-mark-mono.svg` | Marque **monochrome** (prend la couleur du texte / `currentColor`) — tampon, gravure, fax |
| `novacces-lockup-light.svg` | Logo **horizontal** (bouclier + « NovAccès »), fond clair |
| `novacces-lockup-dark.svg` | Logo **horizontal**, fond sombre |

## Couleurs de marque

| | Hex | Usage |
|---|---|---|
| Navy pétrole | `#0E2A3A` | Couleur principale, bouclier sur fond clair |
| Ambre | `#F5A300` | Accent « sûreté » — le check, « Accès » du nom |
| Blanc | `#FFFFFF` | Bouclier sur fond sombre |

## Règles d'usage

- **Zone de protection** : laisser autour du logo un espace vide d'au moins la
  hauteur du check ambre. Ne rien coller contre le bouclier.
- **Taille minimale** : marque ≥ 20 px ; verrouillage horizontal ≥ 90 px de large
  (en-dessous, préférer la marque seule).
- **Fonds** : marque *light* sur clair, marque *dark* sur navy/photo sombre.
  Ne pas poser la version navy sur un fond sombre (illisible).
- **À éviter** : déformer, changer les couleurs, ajouter ombre/dégradé/contour,
  incliner, ou remplacer la police du nom.

## Police du nom

Le mot « NovAccès » est en **Barlow Condensed Bold** (repli : Arial Narrow).
Si la police n'est pas installée, les verrouillages s'afficheront avec le repli —
pour un rendu figé, vectoriser le texte (« convertir en tracés ») dans un éditeur.

## Exporter en PNG

Les SVG s'exportent en PNG à la taille voulue via :
- un éditeur (Inkscape, Figma, Illustrator) → « Exporter », ou
- un convertisseur en ligne (déposer le SVG, choisir la taille).

Tailles utiles : 512×512 et 1024×1024 (stores), 180×180 (icône iOS),
64×64 / 32×32 (favicon).
